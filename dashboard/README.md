# RIA Dashboard

Веб-приложение на **NestJS** с **серверным рендером** (Handlebars): страница новостей с поиском, подсказкой тегов и таблицей результатов. Данные приходят не с РИА напрямую, а с сервиса **exporter** по HTTP.

## Как устроено

Фича живёт в `src/news/` и разнесена по слоям в духе **чистой архитектуры**:

- **domain** — сущности и абстрактные репозитории (контракты, без HTTP).
- **application** — сервисы, которые оркестрируют сценарии и зависят только от абстракций.
- **infrastructure** — реализации репозиториев и HTTP-клиент к exporter (`ExporterClient`).
- **presentation** — контроллеры (в т.ч. MVC под дашборд), схемы запросов, шаблоны `.hbs`, маппинг в представление.

Модуль [`src/news/news.module.ts`](src/news/news.module.ts) собирает провайдеры слоёв и настраивает `HttpModule` с базовым URL exporter. У приложения также есть **Swagger** для публичного HTTP API — см. [`src/main.ts`](src/main.ts) (путь `/swagger`).
